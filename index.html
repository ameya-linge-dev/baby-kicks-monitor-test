Privacy and safety

This page does not persist transcripts or send them to Baby Moves servers. The browser’s speech-recognition implementation may process audio using a browser/vendor service; this test does not guarantee offline recognition. Do not use this test page for clinical decisions. Baby movement changes should be discussed with the maternity unit promptly.

Test records exist only in this page's current memory and disappear when it is reloaded. Results should be written down manually for the feasibility decision.
